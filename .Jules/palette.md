## 2026-08-13 - [Hover Clarity for Icon-Only Chat Actions]
**Learning:** Icon-only actions (like thumbs, copy, and fork buttons) in chat bubbles have poor discoverability and can be ambiguous without hover tooltips. When wrapping action buttons nested inside dynamic wrapper components (such as Mantine's `CopyButton`), the `Tooltip` component should wrap the nested `ActionIcon` itself and consume the dynamic `copied` state. This ensures that the tooltip label instantly updates from "Copy message" to "Copied" upon user interaction, providing immediate visual and accessible feedback.
**Action:** Always wrap icon-only controls in `Tooltip`s with an appropriate `openDelay` (e.g., 400ms) to prevent visual noise during scrolling/panning, and utilize dynamic labels for interaction-heavy components like copy helpers.
